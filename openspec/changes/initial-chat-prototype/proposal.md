# Primer prototipo del chat académico

## Why

Se necesita un primer avance pequeño y demostrable que explique AulaNexo y establezca el trabajo con SDD antes de integrar un modelo. Una interfaz local permite revisar el flujo de consulta sin depender de credenciales o servicios externos.

## What Changes

- Documentar problema, alcance, arquitectura futura e instrucciones del sistema.
- Preparar una interfaz web local en español con identidad AulaNexo.
- Permitir mensajes en memoria y respuestas fijas explícitamente identificadas como demostración.
- Mostrar preguntas sugeridas y el estado pendiente de los documentos.
- Incorporar comandos reproducibles de ejecución, compilación y validación.

## Capabilities

### New Capabilities

- `chat-prototype`: interfaz de demostración, entrada de consultas y reinicio de conversación.

### Modified Capabilities

Ninguna: el repositorio parte vacío.

## Impact

Se añaden archivos estáticos, Vite y OpenSpec como dependencias de desarrollo y documentación académica. No se crean APIs, bases de datos, llamadas a modelos ni despliegues. El alcance final del proyecto se registra como trabajo pendiente.
