# Instrucciones del proyecto

- Respetar la identidad Git configurada. No sobrescribir `user.name` ni `user.email`.
- No usar identidades de asistentes como autor o committer ni añadir trailers `Co-authored-by` o atribuciones de elaboración automática.
- Trabajar con SDD y OpenSpec: propuesta, requisitos con escenarios, diseño y tareas antes de implementar cada cambio.
- Escribir la documentación y la interfaz en español. Conservar los encabezados y palabras normativas que requiere OpenSpec.
- Mantener pequeño el primer avance. No presentar respuestas de demostración como resultados de un modelo, RAG o herramientas reales.
- No guardar credenciales ni documentos privados en el repositorio.
